## Tasks

### Task 1

1. Generate a random 4×4 NumPy array using an exponential distribution.
2. Compare exponential, uniform, and normal distributions using histograms.
3. Plot `Z = X² + Y²` as a 3D surface.
4. Calculate Pearson and Spearman correlations and visualize them using heatmaps.

### Task 2

1. Load the Au nanoparticle dataset.
2. Select the `N_total`, `N_bulk`, `N_surface`, and `R_avg` features.
3. Display the first 20 records.
4. Calculate mean, standard deviation, and quartiles.
5. Create histograms using a 1×4 layout.
6. Create Seaborn pairplots.
7. Create a customized PairGrid with histograms and KDE plots.
